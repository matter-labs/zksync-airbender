# Verification status

Current state; update the tables after each completed task.
**Checked** means kernel-checked soundness of the imported richer no-cache
constraints under the interfaces in `Review/`. Standard ISA behavior comes from
pinned Sail; Clean is the sole constraint model. Logical matching, table
membership and import/generation fidelity remain explicit trust boundaries.
Interrupts, exceptions and cryptographic prover/verifier soundness are outside
these trace claims.

## Machine checking

The full-family baseline has **151 artifact-import checks and 839 audited declarations**;
the focused trace targets have **33 importer guards and 1104 audited declarations**.
Accepted and rejected fixtures exercise aliases, public decoding/configuration,
clocks/rollover, native histories, memory transport and actual Sail retirement.
A native LBU fixture reads a nonzero byte from its own public instruction while
the ROM permutation token remains zero, using the primary pooled claim.
Accepted per-circuit fixtures cover all four comparisons, six branches with PC
wraparound, and aliased JALR; noncanonical declared PCs are rejected.
A scrambled external-read → XOR → external-read fixture checks complete mixed Sail
execution to PC 12, final x1 = 0xbeef and consumed count 2; swapped and short streams
are rejected. Actual CSR/XOR decoding is checked against public bytes; malformed
CSR forms and a missing imported read selector are rejected. The mixed fixture
also realizes the final external response in actual Sail register history,
derives every port bound, and rejects a fabricated intermediate read through
global matching. Standard and custom rows retire from their actual grouped histories,
without caller-supplied reads or bounds. Unified fixtures also check aliased register accesses across clock rollover and reject a fabricated read despite satisfying local equations. Unified RAM LW/SW fixtures instantiate original Sail retirement from actual public instruction/data bytes and native matching. A concrete pooled wide-XOR fixture checks the reused byte relation and rejects an incorrect result. Complete unified XOR/OR/AND rows instantiate native Sail retirement from public bytes and initialized history without operand-range, expected-read or result premises. Public unified decoder fixtures cover arithmetic, memory, jumps/comparisons and shift/binop masks/tags; an accepted native alias row fetches from actual bytes, and wrong tags/selectors are rejected. Keccak controller fixtures cover initial Iota/Theta physical slots, last Chi slots, the 24-round layout cycle, separate padding and invalid-round fallback. Keccak Theta/Rho fixtures satisfy ten imported rows, cover all 25 rotations, bind actual limb transfers and reject incorrect writes. Keccak D-mix fixtures satisfy both native rows with nontrivial limbs, bind actual control/scratch transfers, match Clean’s thetaD and reject an incorrect write. Keccak Iota fixtures cover the initial pass, last round constant and unaffected columns, plus wrong-write rejection. Keccak Chi fixtures satisfy both imported rows with nontrivial high/low bytes, connect their actual scratch writes/reads, match Clean's reference and reject an incorrect final write. A complete native BLAKE2 G row binds its seed tokens to actual public Sail registers/bytes and proves G soundness through initialized history without operand-range premises. A complete native Keccak Theta row binds all fourteen seed tokens to actual public Sail registers/bytes and instantiates shared delegation memory, all native read/write/terminal word bounds and actual Sail execution of every access to the exact terminal cells. Delegation clock fixtures check every native query in all four families, the last aligned low-limb clock, and rejection of nonadvancing accesses and out-of-range invocation clocks. Calculation fixtures use the internal row claims; the public family claims retain integrated history. Changed project modules pass warning-as-error checks. Audits allow only
`propext`, `Classical.choice` and `Quot.sound`; no `sorry` or project axioms.
