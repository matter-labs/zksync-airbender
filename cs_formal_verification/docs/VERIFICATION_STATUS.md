# Verification status

The single model is `cs_formal_verification/`. The statements use the shared constraint
description, current cached captures, CleanCore and Lean 4.35. The native machine
corollaries reach complete RV runs and configured Airbender machine runs. They include
ordinary instructions, modular operations and matched standard and split workers.

The gate checks 311 public statements. This includes 128 separate existential
witness statements and 37 fixed-data or import exceptions. Every statement has
a final proof. [The coverage map](../lean/claim_coverage.json) and
[its checker](../lean/scripts/check_claim_coverage.py) reject missing proofs, missing
witness statements, joined soundness/witness claims and unsupported exceptions.
The [axiom audit](../lean/test/Checks/Axioms.lean) and nightly paranoid replay check
the proof dependencies. The [trust guide](TRUST_AND_REVIEW.md) states the external interfaces.

All 16 native setups have complete byte freshness checks. Trusted compiled comparisons
bind their fixed regions and the ROM fixture. Arbitrary public ROM and decoder data use
the explicit public setup binding. This does not prove the Rust generator for every
program. All 11 cached captures have arithmetic preservation and physical witness proofs.
Worker constraints and exact state, request and architectural memory matching remain
explicit interfaces. A sampled field equation does not establish exact natural matching.

Machine witnesses use empty submitted row lists and symbolic initialization windows.
They establish that the full public boot and matching premises can hold. The circuit and
worker witnesses exercise accepted rows and complete reference spans separately.

The full unsigned target excludes `mop.r.N`. Reduced and unified targets admit the
modeled xor-rotate and `mop.rr.N` operations. All three production targets exclude
special5. The separate valid-use claims cover bigint, G, round, hash and both Keccak
reference schedules. Native execution does not assume delegation validity.
The [Sail boundary](../lean/human/Human/ISA/Sail/README.md) lists the machine overrides.
The [findings register](FINDINGS.md) records F01-F13 and the historical AIH dispositions.
